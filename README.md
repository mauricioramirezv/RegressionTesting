# RegressionTesting

Repositorio educativo con ejemplos claros y separados de distintos tipos de pruebas de software:

- regression-testing
- api-testing
- performance-testing
- security-testing

Cada módulo está pensado para uso académico, con ejemplos simples, estructura clara y ejecución desde terminal.

## Requisitos generales

- Python 3.10 o superior
- pip

## Verificar instalación

```bash
python --version
pip --version
